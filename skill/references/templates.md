# 蓝图文件模板（宪章 / 场景文档 / 搭建教程 / README / 定制指南 / 验收清单）

## 一、宪章模板

```
# <蓝图名称> · 宪章
（本文件是全库最高规则，所有提示词必须服从；修改宪章后全库同步生效）

## 角色宪章
本库服务于【角色名称】。一切输出以该角色的工作场景为准。

## 风格规则（G 系列，提示词中以「宪章 G1」形式引用）
- G1：<统一风格条目，如：先结论后论据，每条结论可追溯到来源>
- G2：<…>

## 红线规则（R 系列，提示词中以「宪章 R1」形式引用）
- R1：<红线条目，如：禁止编造；无依据时明确回复「无此信息」>
- R2：<…>

## 命名与结构规范
- <文件/笔记命名规则>
- <目录结构规则>
```

## 二、场景文档模板（每条场景提示词的外壳，结构详见 paradigm-patterns.md）

```
# <编号> <场景名>
**用途一句话**：<解决什么问题、给谁用、拿到什么>

**使用说明**
1. 打开你日常在用的 AI（说明用哪个工具）
2. 复制下面代码块里的完整提示词
3. 一键发出（如需等待，写明大概时长）
4. <你会得到什么>

**提示词（直接复制）**
<一条 LangGPT 八模块提示词；组织专属内容一律替换为【】占位符>

**拿到结果之后**
<先看什么、再看什么，按优先级列>

**重跑/维护建议**（如适用）
<多久重跑一次、什么情况下更新>
```

## 三、搭建教程模板（B 型结构）

```
# <蓝图名称> · 搭建教程
**流程总览**：共 N 步。<一句话执行原则，如「一步一个动作；先搭最小可用版本，再用真实材料测试手感」>
步骤 1：<名称> 步骤 2：<名称> …

## 步骤 1 <动作名>
**为什么做**：<人话，一两句>
**怎么做**：
<完整可复制提示词块或具体操作>
**完成后你能看到**：<可验证的结果>
**注意**：<最常见的错误>

## 步骤 2 …
（每步同样四件套）

## 最后一步 全面检查/测试
只做检查、列出问题，不直接改动内容；再用一个简单的真实任务测试。
```

## 四、README 模板

```
# <蓝图名称> · 使用说明

## 这是什么
一句话：<为哪个角色、解决什么问题、产出什么>。

## 快速开始（3 步）
1. <装/导入到哪>
2. <先读哪个文件：宪章>
3. <第一次使用：从哪条开始>

## 目录结构
- 宪章：<作用>
- 搭建教程：<从 0 到 1 的完整流程>
- 场景/<编号-场景名>：<每条的用途一句话>
- 定制指南：<什么情况下需要看>

## 适用与不适用
- 适用：<场景边界>
- 不适用：<明确排除的场景>
```

## 五、定制指南模板

```
# <蓝图名称> · 定制指南（复用到其他组织/角色时阅读）

## 替换清单（复制后逐项替换）
| 占位符 | 含义 | 替换示例 |
|---|---|---|
| 【角色名称】 | 使用这套蓝图的角色 | 区域经营负责人 → 城市经理 |
| 【组织名称】 | 公司/组织 | — |
| … | … | … |

## 需要人工判断的定制点
1. <宪章红线是否要按本组织合规要求增删>
2. <各场景 OutputFormat 的长度与详略是否匹配本组织习惯>
3. <载体差异：若不用同款工具，哪些 Workflow 步骤需调整>

## 定制后自检
按「验收清单」重跑一遍再投入使用。
```

## 六、验收清单模板

```
# <蓝图名称> · 验收清单

## 结构完整性
- [ ] 宪章含角色宪章 + ≥2 条风格规则 + ≥2 条红线
- [ ] 每个场景对应且仅对应一份场景文档（范式外壳 + LangGPT 提示词）
- [ ] 每条提示词八核心模块齐全（Role/Profile/Goal/Skills/Rules/Workflow/OutputFormat/Initialization）
- [ ] 搭建教程步骤编号完整，每步含四件套（为什么/怎么做/完成后能看到/注意）
- [ ] README、定制指南、占位符清单三件套齐全

## 内容一致性
- [ ] 每条提示词的 Rules 覆盖宪章全部红线，且引用宪章编号
- [ ] 每条提示词的 Goal 与规格卡验收标准对应
- [ ] 占位符用法全库一致，无硬编码的组织/角色专属内容
- [ ] 占位符清单与定制指南替换表一一对应

## 非技术友好性
- [ ] 术语首次出现均有人话解释
- [ ] 每条提示词为完整复制块，无需拼装
- [ ] 每个步骤写清「完成后你能看到什么」
- [ ] 注意事项有独立标注块

## 可用性抽查（至少抽 2 条提示词实跑）
- [ ] 抽查条目按 Initialization 开场，能正确索要输入
- [ ] 给真实输入跑一遍，输出符合 OutputFormat
- [ ] 故意给越界输入（错误格式/诱导编造），提示词能按 Rules 拒绝或声明无依据
```
