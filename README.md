# ai-idea-planner · AI想法落地规划师

> 把一句「我想用 AI 做个什么」的想法，变成一套不会写代码的人也能照着一步步做完的落地方案：可直接复制的结构化提示词 + 分步搭建教程 + 注意事项 + 验收清单。

## 解决什么问题

很多人会用 AI 聊天，却不知道如何把 AI 真正搭进自己的业务场景：资料想沉淀成知识库、想做一张数据看板、想让 AI 定期自动发内容、想做一个提问式应用——有想法，不知道从哪下手，也看不懂技术文档。

这个项目把「从想法到落地」的全过程方法论化：你只需要按引导填一张场景清单，它就能产出一整套可直接执行的方案，并且全程说人话。

## 适用场景

凡是「想让 AI 真正接进日常工作、而不只是聊天问答」的想法，都可以从这里开始。常见例子：

- 手上有一堆文档 / 笔记 / 会议记录，想沉淀成知识库，让 AI 整理归类、随问随答
- 想给团队攒一套不同场合都能用的提示词，风格统一、红线统一
- 想把一项重复性工作（写周报、审材料、出小结）封装成随时调用的固定能力
- 想做一个看得见的小应用：数据看板、小工具、表单页
- 想让 AI 定期自动干活：内容发布、定时汇总、例行检查
- 想做一类特定对话：述职提问、教练式辅导、模拟演练

不适用：只想优化单条提示词（用专门的提示词优化工具更合适）；不涉及搭建体系的临时问答。

## 怎么用

开口第一句直接说想法就行，说不清楚也没关系——它会先帮你判断属于哪类需求。例如：

- 「我想做一个让 AI 管理我部门资料的知识库」
- 「我想要一套给培训团队用的提示词，风格要直接一点」
- 「我想让 AI 每周自动帮我整理一份发布内容」

之后它会一次性发你一张场景采集清单填写，整理成规格卡交你确认，确认后产出整套可照做的方案。全程不需要写代码，每一步都会写清「做什么、完成后你能看到什么」。

## 它是怎么工作的

六个阶段，严格按序、不跳步：

1. **判定类型**：把想法归入六大能力类型——知识库仓库型 / 提示词库型 / 功能技能型 / 应用型（看板、小工具）/ 自动化型（定期自动执行）/ 对话应用型（提问、教练、述职）。
2. **场景采集**：一次性发出完整的场景采集清单（角色、场景、载体、风格与红线、复用要求），不逐条追问。
3. **规格卡确认**：整理成场景规格卡，由使用者确认后才动手——规格卡是唯一依据。
4. **宪章生成**：先定 G 系列风格规则与 R 系列红线，每条必须具体可判断。
5. **蓝图生成**：每个场景一条 LangGPT 八模块结构化提示词，外加搭建教程、注意事项、README、定制指南与验收清单。
6. **验收迭代**：对照验收清单逐项自查，抽查提示词实跑。

三个设计原则（借鉴开源项目 spec-kit 的规格驱动理念）：宪章先行、规格先于动手、关键节点设人工确认门。

## 仓库结构

```
ai-idea-planner/
├── README.md               本文件
├── LICENSE                 MIT 许可证
├── skill/                  技能包本体（AI 助手可直接加载）
│   ├── SKILL.md            主文档：定位、六阶段流程、硬性规则
│   └── references/
│       ├── checklist.md        场景采集清单与规格卡模板
│       ├── langgpt.md          LangGPT 八核心模块定义与单条提示词模板
│       ├── paradigm-patterns.md 四类场景文档范式（诊断评估/搭建教程/场景卡/批量导入）
│       ├── scenario-types.md   六大能力类型：交付物清单、搭建流程与注意事项
│       ├── templates.md        宪章/场景文档/教程/README/定制指南/验收清单模板
│       ├── example.md          两个完整范例（对齐产出形态与详略）
│       └── writing-style.md    非技术用户友好写作规范
└── expert/                 可选：把本项目做成 AI 助手/智能体时的配置
    ├── system-prompt.md    系统提示词（可直接粘贴）
    └── expert-config.md    专家描述与推荐提问
```

## 快速开始

**方式 A：你的 AI 助手支持「技能 / Skill」机制**
把 `skill/` 整个目录放入工具的技能目录，或打包成 zip 上传安装。之后直接说：「我想做一个让 AI 管理我部门资料的知识库」。

**方式 B：没有技能机制的 AI 助手**
把 `skill/SKILL.md` 的全文粘贴给 AI，再补一句：「请严格按这份流程帮我做：〈你的想法〉」。

**方式 C：自己创建一个 AI 助手/智能体**
使用 `expert/system-prompt.md` 作为系统提示词，`expert/expert-config.md` 里的描述与推荐提问填入配置页。

提示：首次使用建议准备一个真实场景（哪怕很小），按流程完整走一遍，产出质量远高于空对空演示。
